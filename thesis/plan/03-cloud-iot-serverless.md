# Cloud IoT and serverless computing

The chapter will present the technologies that the framework will be built on.

## Internet of Things and MQTT

IoT architectures with devices, gateways and platforms will be described, together with the publish–subscribe model of MQTT.

## AWS IoT Core

Device identities with X.509 certificates, IoT policies, the rules engine and device shadows will be explained, because the telemetry and the remediation commands will pass through them.

## Serverless and event-driven computing

AWS Lambda, EventBridge, Step Functions and DynamoDB will be introduced, together with earlier research on serverless computing for IoT and its known limits, such as cold starts.

## Infrastructure as code and well-architected design

The AWS CDK, infrastructure as code and the AWS Well-Architected Framework will be described as the basis for a reproducible and secure deployment.

## Changes in the AWS IoT portfolio

The end of support of AWS IoT Events, IoT Analytics and Lookout for Equipment will be explained, as it affects the choice of services.
